# Landing Page – Next.js Waitlist App

A modern landing page with a waitlist form built using Next.js App Router, Server Actions, Tailwind CSS, and Airtable as the backend. Deployed on Vercel.

## 🚀 Features

-Next.js App Router (latest architecture)

-Server Actions (no separate API needed)

-Tailwind CSS for styling

-Airtable integration for storing waitlist entries

-Fully responsive landing page

-Production deployment on Vercel

## 🛠 Tech Stack

-Next.js 16 (App Router)

-React

-Tailwind CSS

-Airtable

-Vercel

## 📦 Installation

1.Clone the repository:

git clone https://github.com/yourusername/landing-page.git
cd landing-page


2.Install dependencies:

npm install


3.Create a .env.local file:

AIRTABLE_API_KEY=your_api_key

AIRTABLE_BASE_ID=your_base_id 

AIRTABLE_TABLE_NAME=your_table_name 


4.Run locally:

npm run dev

Open: http://localhost:3000
